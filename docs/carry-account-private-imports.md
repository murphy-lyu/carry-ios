# 账户私有文件导入

账户文件入口通过所属 `TripStore.assetImporter` 显式注入 `CarryAccountImportService`。访客 Store 保持原导入目录。账户相机、文件和照片选择器的临时文件先以租约持有，再进入账户独立不可变缓存，业务模型只保存 `carryasset1_…` 路由标记。账户文件不写入全局 Attachments / TripBackgrounds，访客孤儿回收无法删除这些字节。

附件在准备阶段分配实体 UUID，`NewAttachmentData.id`、缓冲表单与 `TripStore.addAttachment(id:)` 保持同一身份。缓冲表单持有文件租约，实际保存成功后才 adopt；取消、替换、删除待添加项或保存失败均保留正确清理归属。不可变缓存的租约释放仅撤销准备 pin，不直接删除可能已被其它日志或上传任务引用的快照。物理回收仍须合并原生模型、未消费日志、上传任务、在途请求和导入准备 pin，并共享工作区串行门禁。

照片回溯仍只读取系统选择器中主动选取的照片，不申请 PHAsset / 全相册权限。账户模式在读取所选原图字节时直接保存私有快照，`PhotoDraft` 持有原图准备租约；确认入库时沿用预分配照片 UUID。账户照片的 `assetLocalIdentifier` 使用私有文件标记，访客模式沿用原相册引用。原图准备最多同时处理两张；读取或缓存失败中止本批并提示重试，避免静默漏掉选中照片。保存失败保留预览草稿。

行程背景由同一账户导入服务在 utility 任务中缩放到 1400px 并编码 JPEG，随后保存私有快照。根文件访问注册表只在当前账户 lease 内解析经校验的路由标记。

Quick Look 的 URL 入口无法额外传入附件 UTI。账户缓存文件保留 `.blob` 身份，预览通过私有临时目录中的带扩展名别名打开；优先 hard link，跨卷时使用文件复制，不把原文件载入主线程。预览取消或关闭仅释放该别名，原不可变文件保留。合成 PDF 的扩展名、字节一致性及别名删除已加入测试；实际 Quick Look 界面仍需设备验收。

这组导入不授予上传现有行程的权限，也不改变账户发布门禁。导入依赖、文件访问 lease、原图/附件队列、下载投影与退出取消需由账户 Controller 统一装配；仅有组件编译不能作为入口已完成的证明。

复核补充：原生投影为 `StopPhoto.assetLocalIdentifier` 写入当前已验证的 `originalAssetID` 对应私有缓存标记；标量更新保留这个本地指针。旧设备 Photos 标识或复制源实体的缓存标记不作为新原图的最终本地指针。原图阅读器的最终真机视觉验收仍待完成。
